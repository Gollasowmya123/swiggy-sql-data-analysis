# Swiggy Restaurant Data Analysis Using SQL

## 1. Project Overview

This project analyzes Swiggy restaurant data using MySQL.
The analysis focuses on restaurants, cities, cuisines, ratings,
rating counts, and costs.

## 2. Dataset

Dataset: Swiggy Restaurants Dataset

Source: Kaggle

## 3. Tools Used

- MySQL
- MySQL Workbench
- SQL

## 4. Data Cleaning

- Checked total records
- Checked missing values
- Cleaned restaurant names and cities
- Converted ratings into numeric values
- Converted rating counts into numeric values
- Converted restaurant cost into numeric values
- Checked duplicate IDs
- Checked invalid ratings
- Created the final table `swiggy_final_cleaned`
